# Pre-Interview Assessment

A simulated graduate online assessment for Career Readiness students: work-style questionnaire, situational judgement, timed numerical and verbal reasoning, and a downloadable career-development report.

Live: https://will2040.github.io/pre-interview-assessment/

Developed by: Prof Willard Emmanuel Tan | (c) Copyright 2026. All rights reserved.

Work-style items are from the International Personality Item Pool (IPIP Big-Five Factor Markers, Goldberg 1992), which is in the public domain.
